# Phase 1 – Brainstorming & Ideation

## Project Title
Streamlining IT Procurement – Automating Standard Laptop Orders with Flow Designer

## Objective
The objective of this project is to streamline the IT procurement process by automating standard laptop orders using ServiceNow Flow Designer.

## Problem Statement
The existing IT laptop procurement process may involve manual approvals, repetitive tasks, delays, and lack of process visibility. This project aims to automate the standard laptop ordering workflow.

## Proposed Solution
A ServiceNow-based automated workflow will be designed using Flow Designer to handle standard laptop requests, approvals, and procurement-related activities.

## Key Benefits
- Reduces manual effort
- Improves approval workflow
- Reduces processing time
- Provides better visibility
- Standardizes laptop procurement
- Minimizes repetitive tasks

## Expected Outcome
A streamlined and automated IT laptop procurement workflow that improves efficiency and reduces manual intervention.
