# Phase 7 – Project Documentation

## Project Title
Streamlining IT Procurement – Automating Standard Laptop Orders with Flow Designer

## 1. Project Overview

This project focuses on automating the standard IT laptop procurement process using ServiceNow Flow Designer.

## 2. Problem Statement

Manual laptop procurement processes can involve repetitive activities, approval delays, and limited visibility of request status.

## 3. Proposed Solution

A ServiceNow Flow Designer workflow is used to automate laptop request processing, approval, procurement activities, notifications, and status updates.

## 4. Objectives

- Automate laptop procurement requests
- Reduce manual effort
- Improve approval processing
- Provide request status visibility
- Standardize the procurement workflow

## 5. Technologies Used

- ServiceNow
- Flow Designer
- GitHub
- Web Browser

## 6. System Workflow

User submits request  
↓  
Request validation  
↓  
Approval  
↓  
Approved / Rejected  
↓  
Procurement processing  
↓  
Status update  
↓  
Notification  
↓  
Completion

## 7. Project Phases

1. Brainstorming & Ideation
2. Requirement Analysis
3. Project Design
4. Project Planning
5. Project Development
6. Project Testing

8. Project Demonstration

## 8. Expected Benefits

- Reduced manual processing
- Faster workflow execution
- Improved process visibility
- Consistent approval handling
- Better request tracking

## 9. Testing

The workflow will be tested using valid requests, invalid requests, approved requests, and rejected requests.

## 10. Conclusion

The project provides an automated approach for managing standard laptop procurement requests using ServiceNow Flow Designer.
