# Phase 4 – Project Planning

## Project Title
Streamlining IT Procurement – Automating Standard Laptop Orders with Flow Designer

## 1. Project Objective

The objective of this project is to plan the development and implementation of an automated standard laptop procurement workflow using ServiceNow Flow Designer.

## 2. Project Scope

The project covers:

- Standard laptop request submission
- Request validation
- Approval workflow
- Automated procurement processing
- Request status tracking
- Notifications
- Testing and documentation

## 4. Development Plan

### Step 1 – ServiceNow Setup
Create and configure the required ServiceNow environment.

### Step 2 – Request Configuration
Configure the standard laptop request information.

### Step 3 – Flow Designer
Create the automated procurement workflow.

### Step 4 – Approval Configuration
Configure the required approval process.

### Step 5 – Notifications
Configure notifications for important workflow events.

### Step 6 – Testing
Test different request and approval scenarios.

### Step 7 – Documentation
