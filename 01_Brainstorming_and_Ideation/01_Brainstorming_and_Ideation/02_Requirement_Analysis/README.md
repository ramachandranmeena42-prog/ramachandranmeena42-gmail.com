# Phase 2 – Requirement Analysis

## Project Title
Streamlining IT Procurement – Automating Standard Laptop Orders with Flow Designer

## 1. Introduction
This phase identifies and analyzes the requirements needed to automate the standard laptop procurement process using ServiceNow Flow Designer.

## 2. Existing System
In the existing process, employees submit laptop requests and the requests may require manual verification, approval, and procurement activities.

### Problems in the Existing System
- Manual request processing
- Delays in approval
- Repetitive administrative tasks
- Lack of process automation
- Difficulty in tracking request status
- Higher possibility of human error

## 3. Proposed System
The proposed system uses ServiceNow Flow Designer to automate the standard laptop procurement workflow.

The system will:
- Receive laptop requests
- Validate request information
- Trigger approval workflow
- Process approved requests
- Update request status
- Provide better visibility of the procurement process

## 4. Functional Requirements

### FR1 – Laptop Request
The system shall allow users to submit a standard laptop request.

### FR2 – Request Validation
The system shall validate the required request information.

### FR3 – Approval
The system shall trigger the required approval process.

### FR4 – Automated Workflow
The system shall execute the procurement workflow automatically using Flow Designer.

### FR5 – Status Tracking
The system shall maintain and update the status of the laptop request.

### FR6 – Notification
The system shall provide notifications when important workflow events occur.

## 5. Non-Functional Requirements

### Performance
The workflow should process requests efficiently.

### Reliability
The automation should execute consistently without unnecessary manual intervention.

### Security
Only authorized users should be able to access and process procurement requests.

### Usability
The request and approval process should be simple and easy to understand.

### Maintainability
The workflow should be easy to modify and maintain.

## 6. Users / Actors

- Employee / Requester
- Approver
- IT Procurement Team
- ServiceNow System

## 7. Hardware Requirements
- Computer or laptop
- Internet connection

## 8. Software Requirements
- ServiceNow
- ServiceNow Flow Designer
- Web Browser
- GitHub

## 9. Expected Result
The system should automate the standard laptop procurement process, reduce manual effort, improve approval processing, and provide better visibility into request status.

## 10. Conclusion
The requirement analysis provides the foundation for designing and developing the automated IT procurement workflow.
